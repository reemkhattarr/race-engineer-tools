# Circuit Map Cleaner

Upload a circuit-map image and get back a clean white-background outline: the
tool removes text, labels, gray secondary-track regions and off-circuit clutter,
keeping only the black track and red direction markers. Preview the result and
download it.

Part of the **race-engineer-tools** project. Source and write-up: see the
project repository.
